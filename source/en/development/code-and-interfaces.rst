Advanced Development
=====================

This section collects deployment/upgrade, source-code building, data contracts,
the public API, and authorized on-site maintenance. Ordinary users completing
first power-on, quick start, non-ROS/ROS2 usage, and troubleshooting usually do
not need to read this section; enter it only for secondary development,
whole-package upgrades, interface semantics, time-source configuration, or
on-site repair. The PTP page is an external Mid-360 example; the TF-card page
must only be performed per the applicable board form and product-support
authorization.
