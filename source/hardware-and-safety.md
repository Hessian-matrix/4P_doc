# 硬件连接与安全

本页建立用户接线和安全检查框架。UART TX/RX 逻辑电平和现有公开 pinout 已确认；相机电气规格、UART Pin 1、FPC 方向、3V3 供电能力和热插拔要求仍待产品确认，不得自行推断。

```{warning}
RoboBaton 4P UART 的 TX/RX 为 3.3V 逻辑电平。只使用 3.3V UART 信号并共地；禁止接入 5V TTL、RS-232 或 USB-UART VCC。`3V3` 引脚的供电方向、允许电流和热插拔能力未纳入 V1 合同。
```

## 供电与热插拔

| 项目 | 当前公开结论 | 用户动作 |
|---|---|---|
| 相机供电电压/电流 | 待产品确认 | 按产品交付说明接线；确认前不要自行改线或外供。 |
| FPC 热插拔 | 待产品确认 | 默认按不支持热插拔处理；插拔前断电。 |
| UART 热插拔 | 待产品确认 | 默认按不支持热插拔处理；避免带电误接 VCC/GND/TX/RX。 |
| 散热要求 | 待产品确认 | 长时间四路编码前确认散热器、风道和工作环境。 |

## UART pinout 与 V1 边界

以下顺序以现有公开板卡**顶视图**为准：接口位于板卡上边缘，按图片方向从左到右读取。

| 接口 | 板端设备示例 | 板卡顶视图从左到右 | TX/RX 电平 | V1 状态 |
|---|---|---|---|---|
| DEBUG_UART | 待产品确认 | `GND / RX / TX` | `3.3V` | 仅公开 pinout；不作为 V1 UART 功能验收入口。 |
| UART7 | `/dev/ttyS7` | `3V3 / RX / TX / GND` | `3.3V` | `serial_port_demo` 可指定该设备，但只交付软件示例。 |
| UART1 | `/dev/ttyS1` | `3V3 / RX / TX / GND` | `3.3V` | `serial_port_demo` 默认设备，但只交付软件示例。 |

公开图片没有标出 Pin 1；从线缆端、连接器插接面或板背面观察时，不得直接把表中左右顺序当作连接器编号。`3V3` 仅表示图片中的引脚标签，不代表 V1 承诺该引脚可为外设供电；供电方向、允许电流和热插拔能力仍待产品确认。

V1 只交付 `serial_port_demo` 软件示例，不把 UART 实际收发、外接线束、USB-UART 适配器或对端设备作为已验收产品功能。公开 demo 默认 `/dev/ttyS1`、`115200`、`txrx`，可通过命令行切换到 `/dev/ttyS7` 或其他设备。接线时只使用 3.3V TX/RX/GND 并共地，不连接适配器 VCC。

## 相机应用资源约束

- `cam-service` 是相机运行依赖，用户文档不建议停止它。
- 相机应用需要独占 camera/VIO/编码资源；切换 `sensor_demo`、`cam_demo` 或其他相机应用前，先正常退出旧相机应用。
- 单颗诊断使用 `cam_demo --camera-id 0/1/2/3 --diagnostics`，每次只运行一个相机 demo。
