## 千兆以太网

板端为 GH1.25 8P 接口，通过配套线缆连接 RJ45。接线图中 GH1.25 针号自上而下为 `8、7、6、5、4、3、2、1`，信号、线色及 RJ45 对应标注随针号同步排列；RJ45 端按图中的 T568B 针号和线色对应连接。自制线缆时须复核端子编号、壳体方向与导通关系。

```{warning}
配套的千兆网线并非双绞线，传输时可能出现丢包，仅用于测试和临时使用。需要可靠的千兆网络连接时，请自行制作或准备符合千兆以太网要求的双绞网线，并按接线图正确连接 GH1.25 与 RJ45；不能仅凭链路协商为千兆就认为传输可靠。
```

## 相机接口

相机物理接口与软件映射如下：

| 物理丝印 | 软件相机 ID | 默认 RTSP 端口 | ROS2 prefix |
|---|---:|---:|---|
| CAM1 | cam0 / camera ID 0 | `554` | `/robobaton/cam0` |
| CAM2 | cam1 / camera ID 1 | `555` | `/robobaton/cam1` |
| CAM3 | cam2 / camera ID 2 | `556` | `/robobaton/cam2` |
| CAM4 | cam3 / camera ID 3 | `557` | `/robobaton/cam3` |

RTSP path 为 `/PRR`，H.264 默认、H.265 可选。NV12 native `1280x1088`，可经 VSE 整幅缩放至 `640x480`/`720x480`/`1280x720`；旋转 `90/270` 时宽高交换。相机 A/B 水平 FOV 保持 `148.4°`/`115.6°`，其余相机参数见[产品介绍](Product_Introduction.md)。

## 供电、热插拔与散热

| 项目 | 公开结论 |
|---|---|
| 主板供电 | XT30 输入 `12–27 V DC`，按实物正负极标识接线。满负载电流、反灌保护和 USB-C 电源角色仍待确认；只使用产品支持确认匹配的电源，不将 USB-C 数据接口视为供电输入。 |

| 散热 | 风扇接口出厂已接好风扇；保持散热器与风道畅通，V2 温控与满负载散热能力须按实际系统验证。 |

## UART

| 接口 | 用途 | 板端设备 | 电平与连接器 | 原理图针号与信号 |
|---|---|---|---|---|
| UART1 | 普通用户串口 | `/dev/ttyS1` | `3.3V`，CN1，GH1.25 4pin | 1：3V3；2：RX；3：TX；4：GND |
| UART7 | 普通用户串口，独立 IO 默认 PPS 输入 | `/dev/ttyS7` | `3.3V`，CN2，GH1.25 5pin | 1：3V3；2：TX；3：RX；4：PPS 输入；5：GND |
| DEBUG_UART（图中 D-UART） | 系统控制台，不用于 `serial_port_demo` | 调试终端 `921600` baud | `1.8V`，SH1.0 3pin | 1：TX；2：RX；3：GND |

UART7 的 4 号针为独立 PPS 输入，不占用 RX/TX，系统默认启用，无需引脚切换；它不是 RTS/CTS。针号与线序须按上图及实物标识核对。PPS 使用 **3.3V 逻辑电平**并须共地；1.8V、5V TTL 或 RS-232 输出须先适配电平，不能直连。断电接线，板端掉电或休眠时禁用或隔离外部 PPS 及其上拉，防止反灌。接线步骤和输入检查见[PPS 同步](../time-sync/pps-sync.md)。

USB-UART 默认只连接 TX/RX/GND，不接 VCC；确认 TX/RX 交叉、适配器电平与共地，防止向板端电源轨反灌。

## 触发与采样

所有相机采集入口统一使用 VIN LPWM 硬件触发。相机与 IMU FSYNC 的物理触发线已统一到同一 IO，不使用软件 GPIO 触发。IMU INT1 为 `34120000.gpio` offset `8`。共用触发线不自动建立 IMU FIFO 样本与图像曝光的一一对应；时钟域、触发捕获和样本关联必须分别验证，不能把到帧时刻当作 LPWM 触发时刻。

## 相机应用资源约束

- 保持相机依赖 `cam-service` 运行，不停止或重配该服务。
- 切换 `sensor_demo`、`cam_demo`、ROS2 或自研相机应用前，先正常退出旧应用，不能同时占用 camera/VIO/编码资源。
- 单颗诊断使用 `cam_demo --camera-id 0/1/2/3 --diagnostics`，每次只运行一个相机 demo。
