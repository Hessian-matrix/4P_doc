# 项目简介

`4P_doc` 是当前仓库的在线文档入口。当前已经完成 Read the Docs 所需的最小 Sphinx 架子，后续可以在 `source/` 目录下继续增加 Markdown 或 reStructuredText 页面。

建议后续按主题拆分章节，例如：

- `quick-start.md`：快速开始、环境准备、构建与运行。
- `hardware.md`：硬件接口、供电、传感器连接、线序和注意事项。
- `software.md`：软件依赖、配置参数、启动命令和日志位置。
- `calibration.md`：相机、IMU、外参、时间同步等标定流程。
- `troubleshooting.md`：常见问题、诊断命令和恢复步骤。
